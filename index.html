Install Live Roster

It'll get its own icon in your Dock and open in its own window, like any other app.

SafariClick File in the menu bar → Add to Dock… → Add
ChromeClick the install icon at the right end of the address bar, or ⋮ menu → Cast, save, and share → Install page as app…
Microsoft Edge… menu → Apps → Install this site as an app

You'll link Planning Center once inside the installed app.
